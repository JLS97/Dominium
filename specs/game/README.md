# Specs de features del juego

Una spec por mecánica: aldeas, economía, héroes, habilidades, IA, niebla de guerra, etc. Plantilla en `plantilla-feature.md`.

Toda mecánica que venga de los Imperivm originales lleva su origen: recordada, por verificar o adoptada. Las que no vienen del original se marcan como propias. Nadie inventa mecánicas del original: si falta un detalle, se pregunta al autor.
